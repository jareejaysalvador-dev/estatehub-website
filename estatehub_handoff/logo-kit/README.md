# EstateHub.ph — Logo Kit (Concept A, Emerald)

Final direction: **Hub Frame monogram**, emerald green (#22B573) on a midnight-navy
tile (#0E1A2C), paired with the ESTATEHUB.PH wordmark (Montserrat: ESTATE Light,
HUB Bold, .PH SemiBold emerald).

## What's inside

- **svg/icon-primary.svg** — the master icon: navy rounded tile + emerald mark. Use
  this everywhere you need a self-contained square icon (app icon, avatar, social).
- **svg/icon-mark-emerald-transparent.svg** — emerald linework only, no tile. For
  placing directly on dark/navy surfaces (e.g. large signage, embossing).
- **svg/icon-mark-navy-transparent.svg** — navy linework only, no tile. For placing
  directly on light surfaces (e.g. printing on cream paper, single-color use).
- **png/icon-*.png** — the primary icon rasterized at 512, 256, 192, 180 (Apple
  touch icon), 128, 64, 48, 32, and 16px.
- **favicon/favicon.ico** — multi-resolution favicon (16/32/48) built from the
  primary icon.
- **lockups/lockup-dark-transparent.png** — icon + wordmark, transparent
  background, white wordmark — for dark/photo backgrounds.
- **lockups/lockup-light-transparent.png** — icon + wordmark, transparent
  background, navy wordmark — for light backgrounds.
- **lockups/lockup-dark-card.png** / **lockup-light-card.png** — the same
  lockups pre-composited on solid navy / porcelain cards, ready to drop into a
  deck or doc.
- **lockups/header-stamp.png** — a compact, tighter-tracked version sized for
  website header use.
- **preview/homepage-with-new-logo.png** — the new lockup composited into your
  homepage mockup's header, in place of the original wordmark, so you can see
  it in context.

## One open item

The homepage preview swaps the *logo only* — the rest of the page (headline
accent word, divider line, arrow icons) is still your original gold. Emerald
logo + gold accents will read as unintentional side by side. Two ways to
resolve it, your call:

1. Carry emerald through as the site's primary accent (CTAs, dividers, .PH
   accent word) and drop gold entirely.
2. Keep gold as the site's accent color and use emerald only for the logo
   mark itself, treating it as a distinct "brand mark color" the way some
   companies separate their logo color from their UI accent color.

## Usage rules

- Flat color only — no gradients, shadows, or outlines added to the mark.
- Keep clear space around the icon equal to the height of the "H" stroke.
- Use the icon alone only at small sizes (favicon, avatar, app icon); pair
  with the wordmark everywhere else.
- Don't stretch, rotate, or reset the wordmark in a different typeface.
- Fonts: Montserrat + Inter, both free (Google Fonts) for commercial use.
- These are original geometric constructions — run a PH trademark/logo search
  before finalizing for commercial launch.
